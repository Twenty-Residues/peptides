# peptides.info

Research-grade reference for peptides. Next.js 15 (App Router) · TypeScript · Tailwind CSS v4.

## Develop

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build

```bash
npm run build && npm start
```

## Deploy

Vercel — connect the `Twenty-Residues/peptides` repo, or `vercel deploy --prod --yes`.
